## 📖 项目简介 (Overview)

**FreeIP Blog (`freeip.blog`)** 是一个面向全球数字游民、科研极客、跨境出海从业者与流媒体爱好者的**高净值决策与技术评测矩阵**。

项目基于现代静态站点架构打造，彻底连根拔除传统模板的各类上游残留，具备 **100% 原创独立性、零暗桩、E-E-A-T 真实测速证据链** 与面向生成式 AI 搜索引擎（Perplexity、ChatGPT Search、Google AI Overviews）的 **GEO（Generative Engine Optimization）** 语义架构。

## 🚀 本地开发与构建 (Quick Start)

### 1. 环境准备
确保您的本地环境满足以下要求：
- **Node.js**: `>= 22.12.0`
- **包管理器**: `pnpm >= 11.24.0`

### 2. 克隆项目与安装依赖
```bash
# 克隆仓库
git clone https://github.com/sksksk98698-source/freeip.blog.git
cd freeip.blog

# 安装依赖
pnpm install
```

### 3. 本地启动开发服务器
```bash
pnpm dev --port 4321
```
打开浏览器访问：`http://localhost:4321`

### 4. 生产环境静态打包构建
```bash
# 执行完整静态构建（生成至 /dist 目录）
pnpm build

# 本地预览编译后的静态产物
pnpm preview
```
